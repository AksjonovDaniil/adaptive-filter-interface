# N2 — Lietotāja modelis un lietotāju klases

Autors: Daniils Aksjonovs

## Apraksts

N2 darbā tiek analizēta adaptīva filtru interfeisa lietotāju uzvedība
noliktavas preču uzskaites tabulai.

Programma:
- aprēķina lietotāju pazīmes;
- veic min-max normalizāciju;
- salīdzina stereotipu klasifikāciju;
- veic k-vidējo klasterizāciju ar k = 2, 3 un 4;
- aprēķina silueta koeficientu;
- klasificē jaunus lietotājus;
- aprēķina EMA;
- demonstrē histerēzi.
